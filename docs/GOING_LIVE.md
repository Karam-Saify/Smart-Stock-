# Live trading is out of scope

Smart Stock is a research and virtual paper-simulation project. It intentionally provides no live broker adapter,
real-order submission, account connection, or deployment checklist for real capital.

Backtests and paper simulations are not evidence of future performance. The current data source is not an audited
point-in-time feed; the universe may contain survivorship and selection bias; costs are illustrative; and simulated
fills omit market impact, intraday liquidity, taxes, foreign exchange and withholding.

Use this project only to study methodology, data quality, uncertainty and simulated execution mechanics. No output is
an investment recommendation.
